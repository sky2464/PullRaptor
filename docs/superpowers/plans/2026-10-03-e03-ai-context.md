## 1. Modules to Introduce / Modify

1. **`src/pullraptor/ai_adapter.py`** (New module, ~180 lines):
   - `AIConfig`, `ExternalContext`, `AIProposal` models.
   - `redact_sensitive_content(text: str) -> str`: RegEx-based secret & credential stripper.
   - `build_explanation_prompt(...)` and `build_context_envelope(...)`: Injection-safe templating.
   - `query_ai_provider(config, prompt, limits, deadline)`: Clean `urllib.request` standard-library JSON adapter for OpenAI-compatible and generic HTTPS endpoints with strict timeout and context truncation.
   - Safe mock/offline fallback for unit tests and local runs.

2. **`src/pullraptor/models.py`** (Update existing):
   - Import `AIProposal` or register proposals field in `FullReport` (optional `proposals: tuple[AIProposal, ...] = ()`).

3. **`src/pullraptor/render.py`** (Update existing):
   - In `render_markdown()`, render an "AI Explanations & Suggestions (Untrusted Proposals)" section if proposals exist, clearly marking them as advisory and model-generated.

4. **`src/pullraptor/__main__.py`** (Update existing):
   - Add CLI options:
     - `--ai-endpoint <URL>`
     - `--ai-model <NAME>`
     - `--ai-token <KEY>` (or env `PULLRAPTOR_AI_TOKEN`)
     - `--context-issue <FILE>` (path to issue description)
     - `--context-ci-log <FILE>` (path to CI error log)

5. **`tests/test_ai_adapter.py`** (New test suite, ~150 lines):
   - Test secret redaction.
   - Test prompt construction & injection neutralization.
   - Test bounded byte ceiling enforcement.
   - Test HTTP mock requests and error handling.
   - Test end-to-end rendering of untrusted proposals.
